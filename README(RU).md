![Version](https://img.shields.io/badge/version-v0.0.12_PRE--BETA-black)
![Platform](https://img.shields.io/badge/platform-Windows_10_|_11_(64--bit)-black)

> **Enhanced Tools Animation Layers Overlay Navigation Interface Application**

 **Languages:** [English](README.md) | [Русский](README(RU).md)

**ETALONIA** — это локальный слой визуального управления в реальном времени для лайв-трансляций и лайв-продакшена.  
Он разработан для работы **вместе с OBS Studio**, а не заменять его.

OBS отвечает за кодирование, запись и стриминг.  
ETALONIA отвечает за структуру сцен, карточки, web-источники, переходы, горячие клавиши и безопасные изменения во время трансляций.

**Текущий публичный статус:** `0.0.12 PRE-BETA`  
**Следующая цель:** стабилизация версии `0.0.13` перед Beta

---

## What ETALONIA is for

ETALONIA создан для трансляций, которым нужно больше, чем базовый список сцен.  
Он помогает управлять визуальной логикой, состояниями шоу, карточками, web-источниками и структурой сцен из одного места — без риска появления редактора в эфире.

Особенно полезен для:

- ток-шоу;
- VTuber и персонажных стримов;
- турниров и игровых шоу;
- викторин;
- панельных обсуждений;
- продакшенов с большим количеством оверлеев;
- длинных трансляций с большим количеством источников;
- сетапов, где сцены OBS становятся сложными для удобного управления.

---

## Why not just OBS?

OBS отлично подходит для кодирования, записи и стриминга.  
ETALONIA отвечает за **логику продакшена вокруг трансляции**.

С ETALONIA вы можете:

- создавать сцены вне OBS;
- держать чистое окно Output для захвата;
- редактировать в реальном времени без показа интерфейса в эфире;
- уменьшить перегрузку сцен OBS, перенеся оркестрацию в отдельный слой;
- управлять карточками, источниками, оверлеями и состояниями сцен из одного рабочего пространства.

Коротко, ETALONIA выступает как слой управления между вашим контентом и OBS.

---

## Typical workflow

1. Запустите ETALONIA.
2. Создайте сцены, карточки, слои и источники в **Editor**.
3. Захватите чистое окно **Output** в OBS.
4. Переключайте сцены с помощью hotkeys.
5. Вносите изменения в реальном времени, при этом вывод трансляции остаётся чистым.

**Editor** — для подготовки и управления.  
**Output** — для самой трансляции.

## Dual-window architecture

### Editor

Рабочее пространство для создания и управления сценами.

### Output

Чистое окно рендера, предназначенное для захвата в OBS.

Окна разделены намеренно:

- Editor не должен появляться в эфире;
- Output остаётся визуально чистым;
- изменения могут применяться на лету;
- редактирование в реальном времени не нарушает финальный вывод.

## Main features

### Scene management

- создание и переключение сцен;
- настройка переходов;
- блокировка сцен для предотвращения случайных изменений перед эфиром;
- использование шаблонов для разных форматов трансляций;
- сохранение и загрузка файлов сцен.

### Layers and objects

Поддерживаемые объекты:

- текст;
- изображения;
- видео;
- аудио;
- web / iframe источники;
- карточки;
- сгруппированные объекты.

Объекты поддерживают:

- порядок слоёв;
- выделение;
- привязку (snapping);
- трансформации;
- состояния видимости;
- опциональное поведение enter / exit анимаций.

### Scene backgrounds and effects

Сцены могут использовать:

- сплошные цвета;
- изображения;
- видео-фоны;
- blur и режимы эффектов.

### Hotkeys

ETALONIA поддерживает настраиваемые горячие клавиши для быстрой работы в Editor и управления Output.  
Профили hotkeys можно импортировать и экспортировать.

## Cards: the core show-control system

Cards — одна из основных систем продакшена внутри ETALONIA.  
Они особенно полезны для:

- игроков;
- гостей;
- состояний;
- карточек тем;
- блоков голосования;
- ролей;
- данных шоу;
- любых интерактивных форматов.

Возможности карточек включают:

- перетаскиваемые и изменяемые по размеру webcam-блоки;
- несколько строк форматированного текста;
- режимы видимости строк;
- режим swap / placeholder;
- позиционирование и размер для каждой строки;
- фон карточки (цвет, изображение или видео);
- поддержку сохранения и загрузки;
- генерацию предпросмотра.

### Card Manager

Card Manager предназначен для быстрой работы с большим количеством карточек.

Возможности включают:

- адаптивную сетку карточек;
- режим активной карточки или всей сцены;
- smart shuffle между карточками;
- smart shuffle внутри одной карточки;
- массовый поиск и замену;
- regex и маски;
- замену URL вебкамер;
- undo для массовых действий;
- быстрые hide / swap;
- drag-and-drop обмен между карточками;
- сохранение и загрузку наборов карточек.

### Card sets and arrays

ETALONIA также включает лёгкий слой данных шоу:

- **Card Set** — сохранение/загрузка групп карточек как `.esccs`;
- **Card Value Arrays** — повторно используемые коллекции значений для массовой замены;
- поддержка импорта/экспорта для текста, `.escva` и JSON-совместимых коллекций;
- токены массивов могут вставляться через форму `массив "Name"`;
- опциональная замена без повторений для заполнения множества карточек без дубликатов значений.

Идея проста: хранить макеты как наборы карточек, данные эпизода как массивы, затем применять всё перед выходом в эфир.

## Web sources

ETALONIA поддерживает iframe источники и источники в стиле VDO / OBS Ninja.

Для ссылок VDO / OBS Ninja приложение пытается нормализовать полезные параметры отображения, где это возможно, такие как чистый вывод, cover и прозрачность.

Доступные настройки включают:

- управление соотношением сторон;
- пресеты разрешения источников;
- пользовательские фоны источников;
- состояние mute;
- статус здоровья / reconnect;
- ручная перезагрузка;
- опциональное плановое обслуживание Output.

Это особенно полезно для продакшенов с большим количеством browser-источников, удалённых гостей и live web-контента.

## Stream Mode

Stream Mode — это облегчённый режим Editor для длинных или ресурсоёмких трансляций.  
Он сохраняет Output на полном качестве, одновременно снижая нагрузку Editor, где это возможно.

Полезен когда:

- используется много iframe или browser-источников;
- идут длинные трансляции;
- ограничены CPU или RAM;
- одновременно запущены игра, браузер, OBS и ETALONIA;
- стабильность важнее полной детализации предпросмотра.

## File formats

ETALONIA использует локальные файлы для сцен, карточек, проектов и коллекций данных.

- `.escf` — файл сцены
- `.escdf` — файл карточки
- `.escprf` — файл проекта / пресета
- `.esccs` — набор карточек
- `.escva`, `.txt`, `.json` — коллекции массивов значений карточек

Пользовательские файлы хранятся локально.  
ETALONIA не требует облачного аккаунта в текущем PRE-BETA процессе.

## Local diagnostics

ETALONIA сохраняет локальные диагностические данные для помощи в обеспечении стабильности и устранении неполадок.

Записываемые данные могут включать:

- события запуска, перезапуска и завершения приложения;
- события консоли рендера;
- IPC heartbeat и сводки синхронизации;
- сводки синхронизации сцен;
- данные производительности Output;
- снимки памяти и защитные события;
- снимки состояния оборудования;
- ключевые события интерфейса, связанные с поведением Editor.

### Storage

Все логи хранятся локально на устройстве пользователя:
```
Documents/ETALONIA/logs
```

### Privacy

- без облачных загрузок;
- без внешней телеметрии;
- без скрытой передачи маркетинговых или персональных данных;
- логи могут автоматически удаляться через 7 дней или после 140 часов общей работы приложения.

Логи предназначены для личной диагностики или добровольной передачи разработчику при устранении проблем.

# System Requirements

| Parameter | Minimum | Recommended |
|-----|-------------------|-----------------|
| CPU | 4 threads | 8+ threads |
| RAM | 8 GB | 16 GB |
| GPU | DX11 / OpenGL 3.3 | Discrete GPU |

**OS:** Windows 10 / 11 (64-bit)  
**Third-party dependencies:** none required  

Большие продакшены с большим количеством вебкамер или browser-источников сильно зависят от поведения браузера, стабильности WebRTC, сетевых условий и доступной видеопамяти GPU.  
Перед важными трансляциями всегда тестируйте сцены на том же оборудовании и сетапе, который планируете использовать.
